# H200 批量训练命令行

目标：四台 H200 server 同时启动四条路线；每台 server 固定一条路线，并在本机 8 张卡上同时跑 3 个模型规格：

| Server | 路线 | `ROUTE` | 第 1 张卡 | 第 2-3 张卡 | 第 4-8 张卡 |
| --- | --- | --- | --- | --- | --- |
| Server-1 | oft | `p0_oft` | Qwen3.5-0.8B | Qwen3.5-4B | Qwen3.5-9B |
| Server-2 | adapter | `p1_adapter` | Qwen3.5-0.8B | Qwen3.5-4B | Qwen3.5-9B |
| Server-3 | lora | `p2_lora_oft` | Qwen3.5-0.8B | Qwen3.5-4B | Qwen3.5-9B |
| Server-4 | pi | `p4_pi` | Qwen3.5-0.8B | Qwen3.5-4B | Qwen3.5-9B |

注意：

- 这里的四个 server 是四台机器分别运行一条路线；每台机器内部同时启动 3 个训练进程。
- 本文档按 CUDA 本地编号写：第 1 张卡是 `CUDA_VISIBLE_DEVICES=0`；第 2-3 张卡是 `CUDA_VISIBLE_DEVICES=1,2`；第 4-8 张卡是 `CUDA_VISIBLE_DEVICES=3,4,5,6,7`。
- 每台 server 内 3 个训练进程必须使用不同 `MAIN_PROCESS_PORT`，本文固定为 `32100/32110/32120`。
- 本文档使用 `examples/calvin/train_files/run_route_validation_train.sh` 直接训练。不要用 `run_h200_fastexplore_route.sh` 做混合模型批量训练，因为该脚本当前会强制 `BASE_VLM == H200_QWEN35_9B`，0.8B/4B 会被拒绝。
- Qwen4B 的本地目录名如果不是 `Qwen3.5-4B`，只改 `QWEN35_4B` 这一行；不要改脚本绕过 `config.json` 检查。
- Adapter / lora-adapter 路线的 `ADAPTER_HIDDEN_DIM` 必须等于当前 Qwen 模型的 hidden size。这里统一用 `auto`，训练脚本会从每个 `BASE_VLM/config.json` 自动解析；不要固定写 `2048`，否则 0.8B/4B/9B 混跑会维度不匹配。
- 存储策略：每 `1000` step 保存一次；普通 checkpoint 只保留最新一个；`10000/20000/30000` 这三个里程碑永久保留。新 checkpoint 成功写完后才删除旧 checkpoint。
- 对照策略：默认是纯视觉 baseline；如果要跑“带本体感受/state”的对照版，必须显式设置 `INCLUDE_STATE=true`，并让 Adapter 路线同时设置 `ADAPTER_USE_PROPRIO=true`。CALVIN LeRobot 的 state 维度是 `8`。

## 0. 每个新终端先初始化环境

四台 server 的每个新终端都先执行这一段。不要省略 `PATH` 和 `source conda.sh`，否则 Inspire Studio 里可能出现 `conda: command not found` 或激活后仍使用 base Python。

```bash
cd /inspire/qb-ilm2/project/26summer-camp-10/26220216/starVLA_Project
export PATH="/inspire/qb-ilm2/project/26summer-camp-10/26220216/miniconda3/bin:$PATH"
source /inspire/qb-ilm2/project/26summer-camp-10/26220216/miniconda3/etc/profile.d/conda.sh
conda activate starVLA_qwen35
```

确认当前终端进入了项目根目录和目标环境：

```bash
pwd
which python
python -c "import sys, transformers; print(sys.executable); print(transformers.__version__)"
```

预期 `pwd` 是：

```text

```

预期 Python 是：

```text

```

## 1. 公共变量

环境初始化通过后，四台 server 都继续执行这一段：

```bash
export PROJECT_ROOT=/inspire/qb-ilm2/project/26summer-camp-10/26220216/starVLA_Project
export CONDA_ROOT=/inspire/qb-ilm2/project/26summer-camp-10/26220216/miniconda3

export STAR_VLA_PYTHON="${CONDA_ROOT}/envs/starVLA_qwen35/bin/python"
"${STAR_VLA_PYTHON}" -c "import sys, transformers; print(sys.executable); print(transformers.__version__)"

export QWEN35_0P8B="${PROJECT_ROOT}/playground/Pretrained_models/Qwen3.5-0.8B"
export QWEN35_4B="${PROJECT_ROOT}/playground/Pretrained_models/Qwen3.5-4B"
export QWEN35_9B="${PROJECT_ROOT}/playground/Pretrained_models/Qwen3.5-9B"

test -f "${QWEN35_0P8B}/config.json"
test -f "${QWEN35_4B}/config.json"
test -f "${QWEN35_9B}/config.json"

export H200_CALVIN_DATA_ROOT=/inspire/qb-ilm2/project/26summer-camp-10/public/inspire_shared/calvin_abc_d
export H200_CALVIN_DATA_NAME=calvin_task_ABC_D
export H200_CALVIN_DATA_MIX=calvin_abc_d_h200

export ACCELERATE_CONFIG=starVLA/config/deepseeds/deepspeed_zero2_route_validation.yaml
export CONFIG_OFT=examples/calvin/train_files/starvla_train_calvin_qwen35_oft_h200.yaml
export CONFIG_PI=examples/calvin/train_files/starvla_train_calvin_qwen35_pi_h200.yaml

export WANDB_MODE=disabled
export NO_ALBUMENTATIONS_UPDATE=1
export TOKENIZERS_PARALLELISM=false
export PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True

export MAX_TRAIN_STEPS=30000
export SAVE_INTERVAL=1000
export EVAL_INTERVAL=1000000
export CHECKPOINT_KEEP_LATEST=1
export CHECKPOINT_KEEP_STEPS=10000,20000,30000
export LOGGING_FREQUENCY=10

export OBS_IMAGE_SIZE="[224,224]"
export ACTION_DIM=7
export ACTION_HORIZON=8
export NUM_ACTIONS_CHUNK=8
export ACTION_QUERY_NUM=128
export ADAPTER_HIDDEN_DIM=auto
export TRAIN_VARIANT=${TRAIN_VARIANT:-vision}
export INCLUDE_STATE=${INCLUDE_STATE:-false}
export STATE_DIM=${STATE_DIM:-8}
export ADAPTER_USE_PROPRIO=${ADAPTER_USE_PROPRIO:-false}
export PI_STATE_DIM=${PI_STATE_DIM:-}
export LORA_R=64
export LORA_ALPHA=128
export LORA_DROPOUT=0.05
export PI_NUM_INFERENCE_TIMESTEPS=4
export PI_REPEATED_DIFFUSION_STEPS=2
export PI_NUM_TARGET_VISION_TOKENS=32

export DATALOADER_NUM_WORKERS=8

# 四台 server 必须使用同一个 BATCH_NAME，才能汇总到同一个批次目录。
# 纯视觉和本体感受对照版请使用不同 BATCH_NAME，避免日志/checkpoint 混在一起。
export BATCH_NAME=${BATCH_NAME:-20260519_h200_qwen_mix_${TRAIN_VARIANT}_30k_v1}
export BATCH_ROOT="${PROJECT_ROOT}/logs/${BATCH_NAME}"
mkdir -p "${BATCH_ROOT}"

"${STAR_VLA_PYTHON}" - "${QWEN35_0P8B}" "${QWEN35_4B}" "${QWEN35_9B}" <<'PY'
import json
import sys

def resolve_hidden(model_dir):
    with open(f"{model_dir}/config.json", "r", encoding="utf-8") as f:
        cfg = json.load(f)
    text_cfg = cfg.get("text_config") if isinstance(cfg.get("text_config"), dict) else {}
    vision_cfg = cfg.get("vision_config") if isinstance(cfg.get("vision_config"), dict) else {}
    hidden = cfg.get("hidden_size") or text_cfg.get("hidden_size") or vision_cfg.get("out_hidden_size")
    if not isinstance(hidden, int) or hidden <= 0:
        raise SystemExit(f"cannot resolve hidden size from {model_dir}/config.json")
    return hidden

for model_dir in sys.argv[1:]:
    print(f"{model_dir}: hidden_size={resolve_hidden(model_dir)}")
PY

qwen_hidden_size() {
  "${STAR_VLA_PYTHON}" - "$1" <<'PY'
import json
import sys

model_dir = sys.argv[1]
with open(f"{model_dir}/config.json", "r", encoding="utf-8") as f:
    cfg = json.load(f)
text_cfg = cfg.get("text_config") if isinstance(cfg.get("text_config"), dict) else {}
vision_cfg = cfg.get("vision_config") if isinstance(cfg.get("vision_config"), dict) else {}
hidden = cfg.get("hidden_size") or text_cfg.get("hidden_size") or vision_cfg.get("out_hidden_size")
if not isinstance(hidden, int) or hidden <= 0:
    raise SystemExit(f"cannot resolve hidden size from {model_dir}/config.json")
print(hidden)
PY
}

declare -a H200_BATCH_PIDS=()
declare -a H200_BATCH_NAMES=()
declare -a H200_BATCH_LOG_DIRS=()

launch_qwen_size() {
  local model_tag=$1
  local base_vlm=$2
  local gpus=$3
  local num_processes=$4
  local main_process_port=$5
  local adapter_hidden_dim
  adapter_hidden_dim="$(qwen_hidden_size "${base_vlm}")"
  local run_id="${ROUTE_LABEL}_${model_tag}_${MAX_TRAIN_STEPS}step"
  local log_dir="${BATCH_ROOT}/${SERVER_DIR}/${model_tag}/${run_id}"
  local launcher_log="${log_dir}/terminal/launcher.log"
  local env_log="${log_dir}/terminal/env.log"

  mkdir -p "${log_dir}/terminal"
  echo "launch server=${SERVER_DIR} route=${ROUTE} model=${model_tag} gpus=${gpus} port=${main_process_port} adapter_hidden_dim=${adapter_hidden_dim} log_dir=${log_dir}"

  {
    echo "timestamp=$(date -Is)"
    echo "server=${SERVER_DIR}"
    echo "route=${ROUTE}"
    echo "route_label=${ROUTE_LABEL}"
    echo "model_tag=${model_tag}"
    echo "base_vlm=${base_vlm}"
    echo "config_yaml=${CONFIG_YAML}"
    echo "cuda_visible_devices=${gpus}"
    echo "num_processes=${num_processes}"
    echo "main_process_port=${main_process_port}"
    echo "adapter_hidden_dim=${adapter_hidden_dim}"
    echo "train_variant=${TRAIN_VARIANT}"
    echo "include_state=${INCLUDE_STATE}"
    echo "state_dim=${STATE_DIM}"
    echo "adapter_use_proprio=${ADAPTER_USE_PROPRIO}"
    echo "pi_state_dim=${PI_STATE_DIM:-<auto>}"
    echo "max_train_steps=${MAX_TRAIN_STEPS}"
    echo "save_interval=${SAVE_INTERVAL}"
    echo "eval_interval=${EVAL_INTERVAL}"
    echo "checkpoint_keep_latest=${CHECKPOINT_KEEP_LATEST}"
    echo "checkpoint_keep_steps=${CHECKPOINT_KEEP_STEPS}"
    echo "logging_frequency=${LOGGING_FREQUENCY}"
    echo "run_ts=${BATCH_NAME}_${SERVER_DIR}_${model_tag}"
    echo "run_id=${run_id}"
    echo "log_dir=${log_dir}"
    echo "launcher_log=${launcher_log}"
    echo "train_log=${log_dir}/terminal/train.log"
  } > "${env_log}"

  (
    set +e
    echo "===== launcher start $(date -Is) ====="
    cat "${env_log}"
    echo "===== terminal stdout/stderr ====="
    ROUTE="${ROUTE}" \
    BASE_VLM="${base_vlm}" \
    CONFIG_YAML="${CONFIG_YAML}" \
    ADAPTER_HIDDEN_DIM="${adapter_hidden_dim}" \
    INCLUDE_STATE="${INCLUDE_STATE}" \
    STATE_DIM="${STATE_DIM}" \
    ADAPTER_USE_PROPRIO="${ADAPTER_USE_PROPRIO}" \
    PI_STATE_DIM="${PI_STATE_DIM}" \
    CUDA_VISIBLE_DEVICES="${gpus}" \
    NUM_PROCESSES="${num_processes}" \
    MAIN_PROCESS_PORT="${main_process_port}" \
    CHECKPOINT_KEEP_LATEST="${CHECKPOINT_KEEP_LATEST}" \
    CHECKPOINT_KEEP_STEPS="${CHECKPOINT_KEEP_STEPS}" \
    LOGGING_FREQUENCY="${LOGGING_FREQUENCY}" \
    RUN_TS="${BATCH_NAME}_${SERVER_DIR}_${model_tag}" \
    RUN_ID="${run_id}" \
    LOG_DIR="${log_dir}" \
    bash examples/calvin/train_files/run_route_validation_train.sh
    status=$?
    echo "===== launcher end $(date -Is) status=${status} ====="
    exit "${status}"
  ) > "${launcher_log}" 2>&1 &

  local pid=$!
  echo "${pid}" > "${log_dir}/pid.txt"
  H200_BATCH_PIDS+=("${pid}")
  H200_BATCH_NAMES+=("${model_tag}")
  H200_BATCH_LOG_DIRS+=("${log_dir}")
}

launch_three_sizes_for_this_route() {
  H200_BATCH_PIDS=()
  H200_BATCH_NAMES=()
  H200_BATCH_LOG_DIRS=()

  launch_qwen_size qwen35_0p8b "${QWEN35_0P8B}" 0 1 32100
  launch_qwen_size qwen35_4b "${QWEN35_4B}" 1,2 2 32110
  launch_qwen_size qwen35_9b "${QWEN35_9B}" 3,4,5,6,7 5 32120

  local status=0
  local idx
  for idx in "${!H200_BATCH_PIDS[@]}"; do
    local pid="${H200_BATCH_PIDS[$idx]}"
    local name="${H200_BATCH_NAMES[$idx]}"
    local log_dir="${H200_BATCH_LOG_DIRS[$idx]}"
    if ! wait "${pid}"; then
      echo "FAILED model=${name} pid=${pid} log_dir=${log_dir}" >&2
      tail -n 160 "${log_dir}/terminal/launcher.log" >&2 || true
      status=1
    else
      echo "DONE model=${name} pid=${pid} log_dir=${log_dir}"
    fi
  done
  return "${status}"
}
```

## 6. 监控

每个模型目录都会有独立终端日志：

- `terminal/env.log`：本次后台任务的启动参数、GPU、端口、模型路径、hidden dim、run id。
- `terminal/launcher.log`：这个后台任务完整的 stdout/stderr，相当于它自己的终端输出。
- `terminal/train.log`：`run_route_validation_train.sh` 内部训练日志，重点看 step、loss、checkpoint、traceback。

查看每个 job 的启动参数：

```bash
find "${BATCH_ROOT}" -path "*/terminal/env.log" -type f -print -exec sed -n '1,80p' {} \;
```

查看每个 job 的完整终端输出末尾：

```bash
for f in $(find "${BATCH_ROOT}" -path "*/terminal/launcher.log" -type f | sort); do
  echo "===== $f ====="
  tail -n 80 "$f"
done
```

查看最新训练日志：

```bash
find "${BATCH_ROOT}" -path "*/terminal/train.log" -type f -printf "%T@ %p\n" | sort -nr | head -20
```

实时看 step、loss、保存点和错误：

```bash
watch -n 20 '
for f in $(find "${BATCH_ROOT}" -path "*/terminal/train.log" -type f | sort); do
  echo "===== $f ====="
  tail -n 100 "$f" | grep -aE "Step |Checkpoint saved|Training complete|Traceback|failed|Error" | tail -20
done
'
```

查看 checkpoint 是否每 1000 step 增长：

```bash
watch -n 60 '
find "${BATCH_ROOT}" -path "*/checkpoints/*/checkpoints/steps_*" -type d | sort -V | tail -80
'
```
