# H200 AWAC 后训练运行命令

本文档只保留当前实际采用的主线：**Qwen3.5-4B PI-State BC checkpoint -> public CALVIN 数据只读加载 -> dataloader 即时计算 AWAC reward/done -> critic -> actor**。

不要在本流程里复制完整数据集，不要修改 public parquet，不要把 rollout 当作当前主 AWAC 训练数据。

## 1. 环境初始化

```bash
cd /inspire/qb-ilm2/project/26summer-camp-10/26220216/starVLA_Project

export PROJECT_ROOT=/inspire/qb-ilm2/project/26summer-camp-10/26220216/starVLA_Project
export CONDA_ROOT=/inspire/qb-ilm2/project/26summer-camp-10/26220216/miniconda3
export PATH="${CONDA_ROOT}/bin:$PATH"
source "${CONDA_ROOT}/etc/profile.d/conda.sh"
conda activate starVLA_qwen35

export STAR_VLA_PYTHON="${CONDA_ROOT}/envs/starVLA_qwen35/bin/python"
export CALVIN_PYTHON="${CONDA_ROOT}/envs/calvin/bin/python"
export ROLLOUT_PARQUET_PYTHON="${STAR_VLA_PYTHON}"

which python
python -c "import sys; print(sys.executable)"
"${STAR_VLA_PYTHON}" -m accelerate.commands.launch --help >/dev/null && echo "accelerate_module=ok"
```

如果 `accelerate_module=ok` 通过，就不需要安装 accelerate。H200 环境里可能没有 `git`，不要把 `git pull` 当作必需步骤。

## 2. 固定路径与 checkpoint

```bash
export PI_STATE_BATCH_ROOT="${PROJECT_ROOT}/logs/20260519_h200_server1_pi_state_30k_v1"

export H200_CALVIN_DATA_ROOT=/inspire/qb-ilm2/project/26summer-camp-10/public/inspire_shared/calvin_abc_d
export H200_CALVIN_DATA_NAME=calvin_task_ABC_D
export H200_CALVIN_DATA_MIX=calvin_abc_d_h200

export QWEN35_4B="${PROJECT_ROOT}/playground/Pretrained_models/Qwen3.5-4B"
export PI_STATE_CKPT_4B="${PI_STATE_BATCH_ROOT}/server1_pi_state/qwen35_4b/pi_state_qwen35_4b_30000step/checkpoints/pi_state_qwen35_4b_30000step/checkpoints/steps_30000_pytorch_model.pt"

test -f "${QWEN35_4B}/config.json"
test -f "${PI_STATE_CKPT_4B}"
```

实验记录口径：

- 主力后训练模型：`Qwen3.5-4B`
- BC checkpoint：`steps_30000_pytorch_model.pt`
- 9B 只有 `steps_25000`，不得写成 30k baseline

## 3. 严格 readiness 检查

这里确认真实 `success` 可读，并允许训练时即时计算 `reward/done`。注意：**不传** `--assume-success-if-missing`。

```bash
export OUT="logs/awac_readiness_onfly_$(date +%Y%m%d_%H%M%S)"
mkdir -p "$OUT"

"${STAR_VLA_PYTHON}" examples/calvin/scripts/inspect_awac_readiness.py \
  --batch-root "${PI_STATE_BATCH_ROOT}" \
  --data-root "${H200_CALVIN_DATA_ROOT}" \
  --dataset-name "${H200_CALVIN_DATA_NAME}" \
  --data-mix "${H200_CALVIN_DATA_MIX}" \
  --expected-step 30000 \
  --job-expected-step server1_pi_state/qwen35_9b=25000 \
  --allow-on-the-fly-rewards \
  --json-out "$OUT/awac_readiness_strict_success.json" \
  > "$OUT/awac_readiness_strict_success.md"

echo "inspect_status=$?"
sed -n '1,300p' "$OUT/awac_readiness_strict_success.md"
```

必须看到：

- `overall: PASS`
- `success labels: PASS`
- `assume_success_if_missing: False`
- `AWAC reward preprocessing: PASS`
- `state metadata dim: state dim 8`
- `action metadata dim: action dim 7`

## 4. 启动 4B critic

```bash
export CUDA_VISIBLE_DEVICES=0,1,2,3,4,5,6,7
export num_processes=8
export WANDB_MODE=offline

export base_vlm="${QWEN35_4B}"
export bc_checkpoint="${PI_STATE_CKPT_4B}"

export calvin_data_root="${H200_CALVIN_DATA_ROOT}"
export data_mix="${H200_CALVIN_DATA_MIX}"
export include_state=true
export state_dim=8

export compute_rewards_on_the_fly=true
export assume_success_if_missing=false

export run_root_dir="${PROJECT_ROOT}/logs/20260520_awac_pi_state_onfly"
export run_id=awac_critic_pi_state_qwen35_4b_bc30k_onfly

bash examples/calvin/train_files/run_calvin_awac_critic.sh
```

启动后必须看到类似日志：

```text
[AWAC] calvin_task_ABC_D: 803693/1071743 valid transitions (H=8)
[AWAC] calvin_task_ABC_D: computing reward/done on the fly (H=8, gamma=0.996, success_column=success, assume_success_if_missing=False)
AWAC critic phase: actor frozen; training Q network only.
```

## 5. Critic 监控

```bash
export CRITIC_RUN="${PROJECT_ROOT}/logs/20260520_awac_pi_state_onfly/awac_critic_pi_state_qwen35_4b_bc30k_onfly"

find "${CRITIC_RUN}" -maxdepth 3 -type f | sort | grep -E 'log$|txt$|json$' || true
find "${CRITIC_RUN}/checkpoints" -maxdepth 1 -type f -name 'steps_*_critic.pt' -print | sort || true
find "${CRITIC_RUN}/tensorboard" -type f | head || true
```

如果训练仍在当前终端，直接观察进度条即可。若需要另开终端查看，可用：

```bash
find "${CRITIC_RUN}" -type f | grep -E 'log$|txt$' | sort
```

健康标准：

- 第一个 checkpoint：`checkpoints/steps_5000_critic.pt`
- `critic_loss`、`q_mean`、`target_mean` 是有限数，不是 `nan/inf`
- `critic_loss` 不持续爆炸
- TensorBoard 目录有 event 文件

注意：训练启动时 dataloader 可能重建 public 数据目录下的 `meta/steps_data_index.pkl` cache。它不是 parquet 内容，也不是 `success/reward/done` 标签；如果后续要求 public 目录完全零写入，需要另起任务把这个 cache 路径迁到个人目录。

## 6. Critic 中断后的处理

当前 `train_awac_critic.py` 没有严格的 resume 参数。不要把重启训练伪装成从旧 checkpoint 继续训练。

如果进程还活着，继续等：

```bash
ps -ef | grep -E 'train_awac_critic.py|accelerate.commands.launch' | grep -v grep || true
```

如果进程已经死了：

```bash
export OLD_CRITIC_RUN="${PROJECT_ROOT}/logs/20260520_awac_pi_state_onfly/awac_critic_pi_state_qwen35_4b_bc30k_onfly"
find "${OLD_CRITIC_RUN}/checkpoints" -maxdepth 1 -type f -name 'steps_*_critic.pt' -print | sort || true
```

处理原则：

- 已有 checkpoint 只能作为不完整记录，不代表完成 50k critic。
- 若必须继续同一实验，应先实现并验证 resume 逻辑。
- 若只是重新跑，使用新的 `run_id`，例如：

```bash
export run_id=awac_critic_pi_state_qwen35_4b_bc30k_onfly_restart1
bash examples/calvin/train_files/run_calvin_awac_critic.sh
```

## 7. 启动 actor

等 critic 完成后，选择最新 critic checkpoint。推荐先确认存在 `steps_50000_critic.pt`。

```bash
export CRITIC_RUN="${PROJECT_ROOT}/logs/20260520_awac_pi_state_onfly/awac_critic_pi_state_qwen35_4b_bc30k_onfly"
export critic_checkpoint="${CRITIC_RUN}/checkpoints/steps_50000_critic.pt"
test -f "${critic_checkpoint}"

export CUDA_VISIBLE_DEVICES=0,1,2,3,4,5,6,7
export num_processes=8
export WANDB_MODE=offline

export base_vlm="${QWEN35_4B}"
export bc_checkpoint="${PI_STATE_CKPT_4B}"

export calvin_data_root="${H200_CALVIN_DATA_ROOT}"
export data_mix="${H200_CALVIN_DATA_MIX}"
export include_state=true
export state_dim=8

export compute_rewards_on_the_fly=true
export assume_success_if_missing=false

export run_root_dir="${PROJECT_ROOT}/logs/20260520_awac_pi_state_onfly"
export run_id=awac_actor_pi_state_qwen35_4b_bc30k_onfly_critic50k

bash examples/calvin/train_files/run_calvin_awac_actor.sh
```

Actor 输出：

```bash
export ACTOR_RUN="${PROJECT_ROOT}/logs/20260520_awac_pi_state_onfly/awac_actor_pi_state_qwen35_4b_bc30k_onfly_critic50k"
find "${ACTOR_RUN}/checkpoints" -maxdepth 1 -type f -name 'steps_*_pytorch_model.pt' -print | sort || true
```

actor 完成后再做 CALVIN eval / rollout 成功率评估。评估命令使用现有文档 `H200_AWAC后训练PIState检查与Rollout命令.md` 或 `H200_批量测试命令行.md`，这里不重复多路线。

## 8. 不要做

- 不要修改 public parquet。
- 不要对 public 数据跑写入式 `prepare_awac_rewards.py`。
- 不要设置 `assume_success_if_missing=true`，当前数据已有真实 `success`。
- 不要把 9B `steps_25000` 写成 `steps_30000`。
- 不要把 rollout 数据当作当前主 AWAC 训练源。
- 不要改 `H=8`、`gamma=0.996`、chunk return、last-H done 语义来“跑通”。
