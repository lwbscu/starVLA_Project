# H200 批量测试命令行

目标：统一用两个脚本批量评测 H200 上已经训练出的最新 checkpoint，并输出 `results.json` 和 mp4，必要时同时输出 rollout LeRobot 数据集用于后训练调试。

本文档只负责 CALVIN 仿真 eval，不负责训练。训练数据和 eval 数据不要混用：

| 用途 | 路径 | 说明 |
| --- | --- | --- |
| 训练 / AWAC 数据 | `/inspire/qb-ilm2/project/26summer-camp-10/public/inspire_shared/calvin_abc_d/calvin_task_ABC_D` | LeRobot/HF 格式，供 BC/AWAC dataloader 使用 |
| 快速仿真 eval / mp4 可视化 | `/inspire/qb-ilm2/project/26summer-camp-10/public/inspire_shared/calvin_abc_d/task_D_D` | CALVIN D 环境，带 `training/.hydra/merged_config.yaml` |

注意：`task_D_D` 目前只有 `training/`，没有正式 `validation/`。它可以用于 smoke eval / visual eval，不要写成官方 CALVIN validation 指标。

## 9. 失败时先看哪里

每个模型的关键日志：

```text
<EVAL_OUTPUT_ROOT>/<server>/<model>/steps_<step>/env.log
<EVAL_OUTPUT_ROOT>/<server>/<model>/steps_<step>/policy_server/terminal/policy_server.log
<EVAL_OUTPUT_ROOT>/<server>/<model>/steps_<step>/eval/terminal/eval.log
```

常用检查：

```bash
tail -n 200 "${EVAL_OUTPUT_ROOT}/summary.tsv"
find "${EVAL_OUTPUT_ROOT}" -path "*/policy_server/terminal/policy_server.log" -print
find "${EVAL_OUTPUT_ROOT}" -path "*/eval/terminal/eval.log" -print
find "${EVAL_OUTPUT_ROOT}" -name results.json -print
find "${EVAL_OUTPUT_ROOT}" -name "*.mp4" -print | head -50
```

典型问题：

| 现象 | 处理 |
| --- | --- |
| `CALVIN_PYTHON is not executable` | 确认 `${CONDA_ROOT}/envs/calvin/bin/python` 存在，必要时重建/安装 calvin 环境 |
| `Missing CALVIN task oracle config` | 设置 `CALVIN_CONFIG_PATH=/path/to/calvin_models/conf` |
| `CALVIN_ASSET_ROOT not found` | 设置 `CALVIN_ASSET_ROOT=/path/to/calvin_env/data` |
| `No CALVIN eval dataset found` | 显式设置 `H200_CALVIN_EVAL_DATASET_PATH=.../task_D_D` |
| `Address already in use` | 用 `cleanup_policy_server.py --port <port>` 清理端口 |
| 没有 mp4 | 不要关掉 `REQUIRE_MP4=1` 绕过，先看 `eval.log` 和 imageio/ffmpeg 依赖 |
| PI state 结果异常 | 确认使用 `eval_h200_server1_pi_state_latest.sh`，且 `SEND_STATE_TO_POLICY=1` |

## 10. 高标准验收

一次 eval 算通过必须同时满足：

1. 脚本退出码为 `0`。
2. `summary.tsv` 中目标模型状态为 `OK`。
3. 每个模型有 `results.json`。
4. 每个模型至少有一个 mp4。
5. 如果打开 rollout 写盘，每个模型有 parquet、meta 和 video。
6. 没有通过关闭 `REQUIRE_MP4`、换错 eval dataset、减少环境检查来掩盖问题。

最终报告中要区分：

```text
task_D_D smoke / visual eval: 当前工程快速评估
official CALVIN validation: 需要正式 validation 目录后另跑
```
