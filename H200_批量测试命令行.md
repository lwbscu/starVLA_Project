# H200 批量测试命令行

目标：统一用两个脚本批量评测 H200 上已经训练出的最新 checkpoint，并输出 `results.json` 和 mp4，必要时同时输出 rollout LeRobot 数据集用于后训练调试。

本文档只负责 CALVIN 仿真 eval，不负责训练。训练数据和 eval 数据不要混用：

| 用途 | 路径 | 说明 |
| --- | --- | --- |
| 训练 / AWAC 数据 | `/inspire/qb-ilm2/project/26summer-camp-10/public/inspire_shared/calvin_abc_d/calvin_task_ABC_D` | LeRobot/HF 格式，供 BC/AWAC dataloader 使用 |
| 当前实测可用的快速仿真 eval / mp4 可视化 | `/inspire/qb-ilm2/project/26summer-camp-10/26220216/starVLA_Project/calvin/dataset/calvin_debug_dataset` | CALVIN debug 环境，带 `validation/.hydra/merged_config.yaml` 和 `training/.hydra/merged_config.yaml` |

注意：

- 当前 H200 实测中，共享盘 `/inspire/qb-ilm2/project/26summer-camp-10/public/inspire_shared/calvin_abc_d/task_D_D` 没有找到 `.hydra/merged_config.yaml`，不能作为 eval 环境。
- `calvin_debug_dataset` 已在 GPU 服务器上实测跑通 policy server、CALVIN env、`results.json` 和 mp4 输出；它适合 smoke eval / visual eval，不要写成官方 CALVIN validation 指标。
- GPU 无网络服务器可以跑 eval；CPU 有网络服务器不适合跑 4B/9B policy server，9B 已实测在加载后被系统 `Killed`，典型是 OOM。

## 9. 训练集批量测试

目标：用 CALVIN debug dataset 的 `training` split 做快速成功率测试，不输出 mp4，尽量吃满 8 张 GPU。这个模式用于快速扫 checkpoint 是否能在训练环境里产生有效动作，不用于正式 CALVIN validation。

重要边界：

- 这里的“训练集批量测试”指使用 `calvin/dataset/calvin_debug_dataset/training/.hydra/merged_config.yaml` 初始化 CALVIN 环境。
- `EVALTRAIN_RATIO` 控制从 `examples/calvin/eval_files/eval_sequences.json` 中取多少比例的 rollout sequence。例如总数 1000，`0.02` 就跑 20 条 sequence。
- `EVALTRAIN_NUM_SHARDS=8` 会把选中的 sequence 切成 8 份，用于 PI state 这种只有 3 个模型的批次也能吃满 8 张 GPU。
- 分片时会同步传 `EVAL_SEQUENCE_INDEX_OFFSET`，保证 CALVIN language annotation 仍按原始 sequence index 对齐。
- 它不是离线遍历 `calvin_task_ABC_D` 的 17870 个 LeRobot episode；如果要做离线训练集 action loss/replay，那是另一套评估。
- 为了快速测试成功率，必须设置 `DEBUG_MP4=0` 和 `REQUIRE_MP4=0`。这需要最新的 `eval_h200_qwen_mix_latest.sh`，旧脚本会强制写 mp4。

```bash
selected = all_sequences[:num_sequences]
if len(selected) != num_sequences:
    raise SystemExit(f"requested {num_sequences} sequences but only found {len(selected)}")

base = num_sequences // num_shards
extra = num_sequences % num_shards
start = 0
with open(dst / "manifest.tsv", "w", encoding="utf-8") as manifest:
    for shard_idx in range(num_shards):
        count = base + (1 if shard_idx < extra else 0)
        shard = selected[start : start + count]
        shard_path = dst / f"eval_sequences_shard_{shard_idx:02d}.json"
        with open(shard_path, "w", encoding="utf-8") as f:
            json.dump(shard, f, ensure_ascii=False)
        manifest.write(f"{shard_idx}\t{start}\t{count}\t{shard_path}\n")
        start += count
PY

column -t -s $'\t' "${EVALTRAIN_SHARD_ROOT}/manifest.tsv"
```
